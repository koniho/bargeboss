# Montrose moored boat normal maps

Generated by `tools/BakeMooredBoats.java` from the same six rigid boat models as
`montrose-moored-boats-v1.png`. No image-generation prompt is involved.

192 registered 128×128 cells, 16 columns and 12 rows. RG encodes the octahedral world-space face normal; B encodes physical surface
height divided by 64. Alpha is the boat silhouette. This replaces the former
three-channel normal format without adding storage.
Geometry rotates before normals and projection. Camera projection, painter order,
cell origins, pivots and antialiasing match the base artwork. Local cell coordinates
avoid subpixel rounding changes between atlas rows. Decode RGB as data, with no
sRGB-to-linear conversion. At transparent edges, undo premultiplication before
decoding the sampled normal. `boat-surface-light.inc` reconstructs the world
surface position from UV and height and evaluates each independent point light.

Regenerate with the Java sources and `BakeMooredBoats`; run `NormalBoatReview` to
check all silhouettes and height bounds and point-light response and export the red/green lighting board.
